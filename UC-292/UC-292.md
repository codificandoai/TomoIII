# DESCRIPTION
¿Qué es el entorno y cuál es la parte más difícil de la percepción? El ciclo de interacción agente-entorno es el ciclo fundamental de percibir, pensar y actuar. El agente percibe su entorno, piensa para tomar una decisión y luego actúa sobre él, lo que crea un nuevo estado que percibir. Para un agente digital, el entorno es todo su contexto digital: API, bases de datos, sitios web, sistemas de archivos o incluso la interfaz de chat del usuario. La parte más compleja es la percepción. El entorno no proporciona un estado estructurado y ordenado. En cambio, el agente percibe datos des-ordenados y no estructurados, como HTML sin procesar de un sitio web, una respuesta JSON compleja de una API o una solicitud ambigua en lenguaje natural de un usuario. El principal desafío de la percepción reside en analizar estos datos sin procesar y convertirlos en un modelo del mundo significativo y procesable sobre el que el agente pueda razonar.
