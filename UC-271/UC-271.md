# DESCRIPTION

## 1. Objetivo

UC-271 implementa un **sistema Multi-Agent AI desplegable en Kubernetes** con mecanismos avanzados de:

- **Seguridad**: RBAC con permisos mínimos, NetworkPolicy, SecurityContext restrictivo, ServiceAccount dedicado, mTLS.
- **HPA (Horizontal Pod Autoscaler)**: escalado basado en CPU + memoria + métricas custom (queue_depth), cooldown configurable, predicción de carga.
- **Contract Net Protocol**: selección del mejor agente para cada tarea.
- **Observabilidad**: auditoría de seguridad, historial de decisiones HPA, trazas OpenTelemetry.
- **Manifiestos K8s**: generación automática de Deployment, HPA, NetworkPolicy, RBAC, ServiceAccount.

## 3. Pipeline de Ejecución

1. **Recepción de tarea** → API Gateway.
2. **Validación de seguridad** → SecurityContext (nonroot, readonly fs, drop ALL caps).
3. **Contract Net** → Supervisor solicita propuestas concurrentes a todos los workers.
4. **Scoring** → `skill*0.50 + (1/cost)*0.25 + (1/latency)*0.15 + (1/active_tasks)*0.10`.
5. **Selección** → El agente con mayor score gana.
6. **HPA Evaluation** → Se evalúan métricas del ganador para decidir escalado.
7. **Ejecución** → El ganador ejecuta la tarea.
8. **Respuesta** → Resultado + decisión de escalado + contexto de seguridad.

## 4. Seguridad (Security Module)

### 4.1 RBAC — Permisos mínimos por rol

| Rol | Recursos | Verbos |
|---|---|---|
| supervisor | pods, services, deployments, HPA | get, list, watch, create, update |
| researcher | pods, services, configmaps | get, list |
| coder | pods, services, configmaps | get, list, create, update |
| reviewer | pods, services, configmaps | get, list |
| executor | pods, services, configmaps | get, list, create, delete |

### 4.2 NetworkPolicy

- **Ingress**: sólo permite tráfico del supervisor y peers explícitos (puertos 8080, 9090).
- **Egress**: permite salida al supervisor, prometheus y jaeger (puertos 8080, 9090, 14268).

### 4.3 SecurityContext (Pod Security Standards: restricted)

```yaml
securityContext:
  runAsNonRoot: true
  readOnlyRootFilesystem: true
  allowPrivilegeEscalation: false
  capabilities:
    drop: [ALL]
  seccompProfile:
    type: RuntimeDefault
```

### 4.4 ServiceAccount

- Cada agente tiene un ServiceAccount dedicado.
- `automountServiceAccountToken: false` por defecto.
- Anotaciones para Workload Identity (GKE/EKS).

## 5. HPA — Horizontal Pod Autoscaler

### 5.1 Métricas multi-dimensionales

El HPA evalúa tres métricas con pesos:

| Métrica | Peso | Target |
|---|---|---|
| CPU utilization | 40% | 70% |
| Memory utilization | 30% | 80% |
| Queue depth (custom) | 30% | 5 |

### 5.2 Algoritmo de decisión

```python
combined_ratio = cpu_ratio * 0.4 + mem_ratio * 0.3 + queue_ratio * 0.3

if combined_ratio > 1.2:
    → SCALE UP (desired = current * combined_ratio)
elif combined_ratio < 0.5 and current > min_replicas:
    → SCALE DOWN (desired = max(min, current * combined_ratio))
else:
    → NO CHANGE
```

### 5.3 Cooldown

| Dirección | Cooldown por defecto |
|---|---|
| Scale Up | 60 segundos |
| Scale Down | 300 segundos |

### 5.4 Manifiesto HPA generado

```yaml
apiVersion: autoscaling/v2
kind: HorizontalPodAutoscaler
spec:
  minReplicas: 1
  maxReplicas: 10
  metrics:
    - type: Resource (cpu, 70%)
    - type: Resource (memory, 80%)
    - type: Pods (agent_queue_depth, target 5)
  behavior:
    scaleUp:
      stabilizationWindowSeconds: 60
    scaleDown:
      stabilizationWindowSeconds: 300
```

# API

## Card Views — Entrada

### `POST /api/v1/task/run`
Ejecutar tarea con contract net + seguridad + HPA auto-scaling.

```json
{
  "task": "Analyze incident and propose fix",
  "resource": "GPU_1",
  "priority": 7
}
```

### `POST /api/v1/hpa/evaluate`
Evaluar métricas de un agente y obtener decisión de escalado.

```json
{
  "agent_name": "researcher",
  "cpu_percent": 85.0,
  "memory_percent": 75.0,
  "queue_depth": 8,
  "active_tasks": 3,
  "replicas_current": 2
}
```

### `POST /api/v1/security/generate`
Genera políticas de seguridad completas para un agente.

```json
{
  "name": "researcher",
  "role": "researcher",
  "skill": 0.95,
  "cost": 1.2,
  "latency_ms": 250
}
```

### `POST /api/v1/security/validate`
Valida que un agente cumple con las políticas de seguridad.

```json
{
  "name": "researcher",
  "role": "researcher",
  "skill": 0.95,
  "cost": 1.2,
  "latency_ms": 250,
  "service_account": "researcher-sa",
  "replicas": 2
}
```

### `POST /api/v1/manifests/generate`
Genera manifiestos K8s completos para todos los agentes.

```json
{
  "agents": [
    {"name": "researcher", "role": "researcher", "skill": 0.95, "cost": 1.2, "latency_ms": 250, "replicas": 2},
    {"name": "coder", "role": "coder", "skill": 0.90, "cost": 1.0, "latency_ms": 200, "replicas": 2}
  ]
}
```

## 7. Manifiestos K8s generados

| Recurso K8s | Descripción |
|---|---|

| RoleBinding | Vincula SA con Role |
| Deployment | Con securityContext restrictivo y resource limits |
| Service | ClusterIP en puerto 8080 |
| NetworkPolicy | Ingress/Egress con pods permitidos |
