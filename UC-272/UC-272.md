## 3. Compartición de Conocimiento

### 3.1 Pizarra Compartida (Blackboard)

Pizarra versionada con concurrencia, filtrado por confianza y TTL:

- **write(entry)**: publica conocimiento, versiona entradas previas.
- **read(key, min_confidence)**: retorna la entrada más reciente y confiable.
- **read_category(cat)**: todas las entradas activas de una categoría.
- **subscribe(category, callback)**: notificación de cambios.

Categorías: `flight_facts`, `price_intel`, `risk_assessment`, `user_preferences`, `supplier_constraints`, `negotiation_state`, `model_exchange`.

### 3.2 Gossip Protocol

Difusión epidémica de conocimiento sin pizarra central:

- **create_fragment(topic, content, confidence)**: crea y difunde.
- **receive(fragment)**: acepta si es nuevo y mejor que lo existente.
- **Decay**: confianza decae con cada hop (factor configurable).
- **Max hops**: limita propagación (default 3).

## 4. Protocolos de Negociación

### 4.1 Alternating Offers (Rubinstein)

Negociación bilateral con concesión temporal cuadrática:
- Proposer elige mejor opción ajustada por concesión.
- Responder acepta si utilidad >= reserva, sino contrapropone.
- Roles se alternan cada ronda.
- Concesión: `t^exponent` donde `t = round/max_rounds`.

### 4.2 Contract Net Protocol

Licitación con evaluación multi-criterio:
- **Announce**: publica contrato con criterios ponderados.
- **Bid**: agentes envían pujas con costo, duración, confianza.
- **Adjudicate**: score = cost_weight * (1/(1+cost/1000)) + duration_weight * (1/(1+dur/60)) + confidence_weight * confidence.

### 4.3 Vickrey Auction (segundo precio)

Subasta sellada donde el ganador paga el segundo precio más alto:
- Incentiva pujas sinceras (truthful bidding).
- Soporta precio de reserva.
- Single-bidder paga el precio de reserva.

### 4.4 Argumentation

Negociación por argumentación con ataque/defensa:
- Cada argumento tiene: claim, justification, strength, attacks.
- **Net strength**: `strength - 0.2 * attacks_received`.
- Gana el argumento con mayor fuerza neta.

---

## 5. Criterios de Equilibrio

### 5.1 Nash Bargaining Solution

Maximiza: `Π (u_i - d_i)` sujeto a `u_i >= d_i`

Selecciona la opción que maximiza el producto de las ganancias sobre el punto de desacuerdo.

### 5.2 Pareto Frontier

Opciones no dominadas: ninguna otra opción es >= en todo y > en algo.

### 5.3 Kalai-Smorodinsky

Proporcional a los puntos ideales: mantiene la proporción `(u_i - d_i) / (ideal_i - d_i)` lo más uniforme posible.

### 5.4 Weighted Utilitarian

Maximiza: `Σ (w_i * u_i)` donde `w_i` es el peso del agente.

## 6. Ejemplo: Negociación de Vuelo MAD→CUN

Tres agentes negocian:

| Agente | Función de utilidad | Objetivo |
|---|---|---|
| user_proxy | max(satisfacción, confort) | Comodidad + horario matutino |
| budget_agent | min(costo) | Precio <= $600 |
| sustain_agent | min(CO₂) | Menor huella de carbono |

Opciones:

| Vuelo | Precio | Horario | CO₂ | Comfort |
|---|---|---|---|---|
| AA1234 | $650 | 08:00 | 180 | 8 |
| IB5678 | $520 | 14:00 | 210 | 6 |
| UX9012 | $580 | 10:30 | 165 | 7 |
| AF3456 | $720 | 07:30 | 195 | 9 |

**Resultado Nash**: **UX9012** — compromiso óptimo que maximiza el bienestar colectivo.

# API

## Card Views — Entrada

### `POST /api/v1/negotiate/nash`
Negociación multi-agente con Nash Bargaining, Pareto, Kalai-Smorodinsky o Weighted Utilitarian.

```json
{
  "topic": "flight_MAD_CUN",
  "criterion": "nash",
  "profiles": [
    {"agent_id": "user_proxy", "option_utilities": {"AA1234": 8.5, "UX9012": 7.5}, "disagreement_point": 3.0, "weight": 1.0},
    {"agent_id": "budget_agent", "option_utilities": {"AA1234": 4.0, "UX9012": 7.0}, "disagreement_point": 2.0, "weight": 1.0}
  ]
}
```

### `POST /api/v1/negotiate/contract-net`
Contract Net Protocol: announce + bid + adjudicate.

```json
{
  "topic": "book_flight",
  "announcement": {"announcer": "planner", "task_description": "Book MAD-CUN", "evaluation_criteria": {"cost": 0.5, "confidence": 0.3, "duration": 0.2}},
  "bids": [
    {"contract_id": "<uuid>", "bidder": "supplier_a", "cost": 500.0, "estimated_duration_min": 30, "confidence": 0.9},
    {"contract_id": "<uuid>", "bidder": "supplier_b", "cost": 800.0, "estimated_duration_min": 60, "confidence": 0.7}
  ]
}
```

### `POST /api/v1/negotiate/vickrey`
Subasta Vickrey (segundo precio, sellada).

```json
{
  "topic": "gpu_auction",
  "resource_id": "GPU_1",
  "reserve_price": 10.0,
  "bids": [
    {"auction_id": "<uuid>", "bidder": "agent_a", "bid_value": 100.0, "resource_id": "GPU_1"},
    {"auction_id": "<uuid>", "bidder": "agent_b", "bid_value": 80.0, "resource_id": "GPU_1"}
  ]
}
```

### `POST /api/v1/negotiate/argumentation`
Negociación por argumentación con justificaciones y ataques.

```json
{
  "topic": "price_debate",
  "arguments": [
    {"agent_name": "budget", "claim": "Price too high", "justification": "Market avg is $500", "strength": 0.8},
    {"agent_name": "user", "claim": "Quality matters", "justification": "Premium service", "strength": 0.6}
  ]
}
```

### `POST /api/v1/blackboard/write`
Escribir conocimiento en la pizarra compartida.

```json
{
  "key": "flight:MAD_CUN",
  "category": "flight_facts",
  "value": {"airline": "UX", "price": 580},
  "author": "budget_agent",
  "confidence": 0.9
}
```
