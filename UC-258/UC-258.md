## AI-Native Operations & Agentic Patterns
### Caso: Diseño e implementación de un meta-framework de agentes adaptativos basado en propiedades del entorno

**Uso:** Externo / Referencia arquitectónica e implementación ejecutable.

## Descripción
UC-258 implementa un **meta-framework de agentes adaptativos** en Python. El agente inspecciona las propiedades ontológicas del entorno y elige dinámicamente una estrategia de decisión. El caso incluye tres entornos representativos:
1. **Ajedrez**: discreto, determinista, totalmente observable, estático, secuencial, multi-agente.
2. **Planificador de viajes Komerzio.com**: dinámico, parcialmente observable, probabilístico, discreto (opciones), multiobjetivo, secuencial.
3. **Mercado bursátil**: dinámico, probabilístico, parcialmente observable, continuo, secuencial, multi-agente.
El agente no inventa datos: consulta herramientas externas simuladas, valida restricciones, detecta información faltante, pide aclaraciones y produce itinerarios explicables con fuentes, confianza, supuestos y alternativas. Incluye controles de seguridad contra *prompt injection*, PII y acciones irreversibles.

```mermaid

    A[Entorno: Chess / Travel / Stock] -->|properties()| B[Agente Adaptativo]
    B --> C[Strategy Selector]
    C -->|exact_search| D[Planner: Ajedrez]

    C -->|probabilistic_risk| F[Planner: Bolsa]
    D --> G[Ejecutar acción en Environment]
    E --> H[Herramientas externas simuladas]
    F --> I[Actualizar creencias / Kelly]
    G --> J[Memoria + Traza]
    H --> J
    I --> J
    J --> K[Evaluar + Adaptar política]
```

### Flujo del agente adaptativo

1. **Percepción**: `Environment.get_observation()` devuelve datos y variables ocultas con nivel de confianza.
2. **Clasificación**: `StrategySelector` lee `EnvironmentProperties` y elige la estrategia.
3. **Planificación**: `Planner` genera un plan específico (búsqueda exacta, planificación con restricciones, o gestión de riesgo).
4. **Validación**: `SafetyGuard` comprueba *prompt injection*, PII, acciones irreversibles y confirmaciones.
5. **Ejecución**: el agente ejecuta acciones en el entorno, consultando herramientas externas si es necesario.
6. **Memoria**: `AgentMemory` almacena observaciones, acciones, recompensas y creencias.
7. **Adaptación**: si la recompensa es muy baja o cambia el entorno, el agente reduce confianza y actualiza la política.

## Entornos y sus propiedades

| Entorno | Dinámico | Determinista | Observable | Discreto | Episódico | Agentes | Estrategia |
|---|---|---|---|---|---|---|---|
| Ajedrez | No | Sí | Total | Sí | No | 2 | Búsqueda exacta / Minimax |
| Viajes Komerzio | Sí | No | Parcial | Sí | No | 1 | Planificación con restricciones + herramientas |
| Bolsa | Sí | No | Parcial | No | No | N | Inferencia bayesiana + gestión de riesgo |

### Entorno de ajedrez

- Representación simplificada con movimiento de mate `Qd8`.
- Si `python-chess` está instalado y `UC258_CHESS_USE_PYTHON_CHESS=true`, se puede usar FEN y movimientos UCI.
- Recompensa máxima por jaque mate, penalización por movimiento ilegal.

### Entorno de viajes Komerzio.com

- Herramientas externas simuladas: vuelos, hoteles, clima, conversión de divisas.
- Cada resultado incluye `source`, `confidence`, `verified` y `timestamp`.
- Variables modeladas: origen, destino, fechas, presupuesto, preferencias, disponibilidad, precios, políticas, duración, clima.
- El agente detecta información faltante (`return_date`, `budget`) y genera un itinerario con:
  - coste total y moneda,
  - fuente de cada ítem,
  - nivel de confianza,
  - supuestos,
  - alternativas,
  - lista de información no verificada.

### Entorno de mercado bursátil

- Variables ocultas: `hidden_whale`, `hidden_sentiment`.
- Dinámica estocástica con *momentum* y volatilidad.
- El planificador usa una aproximación Kelly simple para tamaño de posición:
  `f* = edge / variance`, limitado al 10% del capital.

## Pseudocódigo del agente adaptativo

```python
from agent.adaptive_agent import AdaptiveAgent
from environments.travel_env import TravelEnvironment
from models import TravelRequest

agent = AdaptiveAgent()
req = TravelRequest(origin="Madrid", destination="París",
                    departure_date="2026-07-15", return_date="2026-07-18",
                    budget=1500)
env = TravelEnvironment(request=req)
trace = agent.run(env, req)

print(trace.selected_strategy)      # constraint_planning
print(trace.reward)
print(env.itinerary.to_dict())      # coste, fuentes, confianza
```

## Seguridad y gobernanza

- **Prompt injection**: patrones de `ignore instructions`, `system prompt`, etc.
- **PII redaction**: emails, teléfonos, tarjetas.
- **Acciones irreversibles**: `book_flight`, `execute_trade` requieren confirmación explícita si `UC258_REQUIRE_CONFIRMATION_IRREVERSIBLE=true`.
- **Abstención ante incertidumbre**: si una herramienta devuelve `confidence` bajo o `verified=false`, el itinerario lo marca como `missing_info`.
- **Trazabilidad**: cada ejecución genera un `AgentTrace` con propiedades, estrategia, acciones, recompensa y errores.

## Ventajas y limitaciones

| Decisión | Ventajas | Limitaciones |
|---|---|---|
| **Interfaz `Environment` unificada** | Facilita comparar entornos y estrategias | Abstrae detalles específicos que pueden requerir extensiones |
| **Selección de estrategia por propiedades** | Explicable y robusta | Propiedades pueden no ser binarias; requiere granularidad fina en entornos híbridos |
| **Herramientas externas simuladas** | Tests offline sin API keys | En producción deben reemplazarse por APIs reales |
| **Itinerario con confianza/fuentes** | Reduce alucinaciones y aumenta transparencia | No garantiza que los datos sean actuales en producción |
| **Seguridad explícita** | Previene acciones irreversibles sin consentimiento | Puede ralentizar flujos conversacionales |
| **Sin LLM obligatorio** | Funciona offline, determinista | Estrategias basadas en lenguaje natural requieren LLM real |
