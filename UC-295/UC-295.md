# UC-295 — ReAct Híbrido con Árbol de Pensamientos (Tree of Thoughts - ToT)

## Resumen

UC-295 añade una capa al cerebro AGI del sistema de trading multi-agente para
superar la limitación clásica del **ReAct lineal**. Un bucle ReAct tradicional
sobresale en tareas paso a paso, pero se atasca o rinde mal cuando hay que
planificar decisiones complejas con **retroceso (backtracking)** y **exploración
paralela de múltiples rutas**.

En el contexto de predicción del siguiente **ask/bid** de un tick bursátil, el
agente consulta varias "APIs de predicción":

- `brain` / `world_model`: predicción neuronal/probabilística del siguiente
  precio (vía `CentralBrain`).
- `technical`: análisis técnico (RSI, tendencia, MACD, etc.).
- `microstructure`: microestructura de mercado (imbalance bid/ask size).
- `sentiment`: sentimiento de noticias.
- `ensemble`: fallback ponderado que combina las ramas exitosas.

Si una rama falla (TIMEOUT, no resultados o confianza baja), el agente no se
queda atascado. En su lugar:

1. **Expande** el árbol de pensamientos en paralelo.
2. **Poda** las ramas muertas (`PRUNED_FAILED`).
3. **Retrocede** (`BACKTRACKED`) a predictores de contingencia.
4. **Sintetiza** un veredicto consensuado ask/bid.

## Arquitectura del framework

```text
+----------------------------------+
|  ReActReasonactToTBrain          |
|  - predict(symbol, ticks, news)  |
+----------------------------------+
              |
              v
+----------------------------------+
|  TickPredictionEnvironment       |
|  - query(source, ctx)             |
|  - fallback_map                   |
|  - failure_sources                |
+----------------------------------+
              |
    +---------+---------+---------+---------+
    |         |         |         |         |
   brain   technical  micro    sentiment ensemble
 world_model predictor predictor predictor fallback
```

### Flujo de ejecución

```text
1. Recibir símbolo, ticks y noticias.
2. Construir snapshot del mercado (percepción + indicadores).
3. Crear raíz del árbol de pensamientos.
4. EXPANSIÓN PARALELA: crear nodos hijos, uno por predictor solicitado.
5. EJECUCIÓN: consultar cada predictor.
   - Si SUCCESS y confianza >= threshold => hoja válida.
   - Si falla => PRUNED_FAILED.
6. BACKTRACKING: para cada rama podada, intentar predictores de contingencia
   definidos en `fallback_map` (sin repetir caminos ya probados).
7. SÍNTESIS: combinar las hojas exitosas mediante promedio ponderado por
   confianza; seleccionar también la mejor hoja individual.
8. Devolver predicción final ask/bid + árbol + traza ReAct.
```

## Cómo supera al ReAct lineal

| Limitación ReAct lineal | Solución ReAct + ToT |
|---|---|
| Un solo `while`: `pensar → actuar → observar` secuencial. | **Expansión paralela** del grafo completo de hipótesis. |
| Si una API falla, el bucle se bloquea o repite el mismo paso. | **Poda**: la rama muere sin afectar a las demás. |
| No puede olvidar un camino fallido y probar otro desde el origen. | **Backtracking deliberado**: vuelve al nodo padre y bifurca hacia contingencias. |
| Olvida resultados intermedios al sintetizar. | **Síntesis convergente**: conserva todas las hojas exitosas y emite veredicto comparativo. |

## API REST

### Endpoints

| Método | Endpoint | Descripción |
|---|---|---|
| `POST` | `/api/v1/tot/predict` | Predice ask/bid del siguiente tick usando el árbol de pensamientos ToT. |
| `GET`  | `/api/v1/tot/docs` | Card views HTML con parámetros de entrada y salida. |

### Input Card View — `POST /api/v1/tot/predict`

| Parámetro | Tipo | Requerido | Descripción / Ejemplo |
|---|---|---|---|
| `symbol` | string | Sí | `"AAPL"` |
| `ticks` | list[object] | Sí | `[{"timestamp":"2026-09-03T10:00:00Z","symbol":"AAPL","bid":150.10,"ask":150.12,"last_price":150.11,"volume":1000,"bid_size":2000,"ask_size":1500}]` |
| `news` | list[object] | No | `[{"text":"AAPL strong earnings","source":"bloomberg"}]` |
| `predictors` | list[string] | No | `["world_model","technical","microstructure"]` |
| `use_brain` | boolean | No | `true` activa `CentralBrain.predict_next_price` como predictor real. |
| `confidence_threshold` | number | No | `0.5` — confianza mínima para aceptar una hoja. |
| `max_depth` | integer | No | `2` — profundidad máxima de backtracking. |
| `simulate_failures` | list[string] | No | `["technical"]` fuerza TIMEOUT para demostraciones/tests. |

#### Ejemplo de petición

```bash
curl -X POST http://localhost:5292/api/v1/tot/predict \
  -H "Content-Type: application/json" \
  -d '{
    "symbol": "AAPL",
    "ticks": [
      {"timestamp":"2026-09-03T10:00:00Z","symbol":"AAPL","bid":150.10,"ask":150.12,"last_price":150.11,"volume":1000,"bid_size":2000,"ask_size":1500}
    ],
    "predictors": ["world_model","technical","microstructure"],
    "simulate_failures": ["technical"],
    "max_depth": 2
  }'
```

### Output Card View — `POST /api/v1/tot/predict`

| Campo | Tipo | Descripción |
|---|---|---|
| `status` | string | `ok` / `error` |
| `request_id` | string | ID de la ejecución. |
| `final_prediction` | object | `predicted_ask`, `predicted_bid`, `predicted_mid`, `spread`, `confidence`, `source_strategy`. |
| `selected_leaf` | object | Mejor hoja individual según score. |
| `consensus` | object | Promedio ponderado por confianza de las hojas exitosas. |

| `leaves` | list[object] | Hojas exitosas con source, ask, bid, confidence. |

## Punto de entrada unificado: `brain.py`

`brain.py` es el CLI principal del cerebro AGI. Conserva las demos heredadas
(UC-294 SAM, UC-293/UC-292 trading) y añade el modo `full` que une todas las
capas:

```bash
# Cerebro AGI completo: SAM + BDI + Juice + World Model + ToT
python code/brain.py --mode full

# Modos individuales
python code/brain.py --mode sam
python code/brain.py --mode trading
python code/brain.py --mode tot

# Ejecutar todas las demos
python code/brain.py --mode all
```

### Flujo del modo `full`

```text
1. Crear un único CentralBrain compartido.
2. run_sam_aware_pipeline()  -> SAM / BDI / Juice / World Model / Trading.
3. Reutilizar el mismo CentralBrain en ReActReasonactToTBrain.
4. ToT predice ask/bid del siguiente tick usando brain + técnicos + microestructura.
5. Imprimir resumen de trading + predicción ToT.
```

## Integración con el cerebro AGI existente

El predictor `brain` se conecta directamente con `CentralBrain`:

```python
from central_brain import CentralBrain
from react_tot import ReActReasonactToTBrain, TickPredictionEnvironment

brain = CentralBrain(get_config())
env = TickPredictionEnvironment(brain=brain)
tot = ReActReasonactToTBrain(env)
result = tot.predict(symbol="AAPL", ticks=ticks, predictors=["brain", "technical", "microstructure"])
```

De esta forma, el ToT no reemplaza el world model: lo utiliza como **una rama
más del árbol**, manteniendo la ventaja de que el veredicto final es robusto
frente a fallos o incertidumbre de cualquier predictor individual.
