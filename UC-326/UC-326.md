# UC-326 — MAQRI: Sistema de Memoria y Búsqueda Inteligente

## 1. Propósito y Alcance

UC-326 implementa **MAQRI** (Memory-Augmented Query Refinement Iterative): la capa de memoria y búsqueda inteligente del agente AGI. Mientras UC-325 es el "cerebro que decide", UC-326 es la "biblioteca inteligente" que:

- Indexa recuerdos, experiencias, memoria episódica y semántica.
- Busca no solo en documentos actuales, sino también en experiencias anteriores del agente, fuentes externas y bases de conocimiento del dominio.
- Refina iterativamente las consultas usando aprendizaje de experiencias pasadas.
- Reúne y ordena la información relevante antes de devolvérsela a UC-325.

Esto convierte al agente en alguien que no solo "busca en un manual", sino que **recuerda qué funcionó antes y mejora la forma de hacer preguntas**.

### Arquitectura de capas

![Arquitectura de capas](./brain_maqri.png)

```
UC-315 (cerebro AGI canónico)
    ↓ consulta
UC-325 (reasoning loop — decide qué necesita saber)
    ↓ pide chunks refinados
UC-326 (MAQRI — memoria y búsqueda inteligente)
    ↓ chunks + metadata
UC-325 evalúa → sintetiza → devuelve a UC-315
```

### Principios

- **UC-315 decide, UC-325 razona/verifica, UC-326 recuerda/busca.**
- UC-326 es una **capa independiente**; no modifica UC-315 ni UC-325.
- Un modelo genera evidencia. La evidencia no es una orden.
- Retrieval inyectable: UC-325 conecta/desconecta UC-326 como componente.

## 2. Arquitectura de Memoria

![MAQRI Architecture](./secuencia.png)

MAQRI estructura la memoria en cuatro componentes:

| Tipo | Función | Implementación |
|------|---------|----------------|
| **Memoria de Trabajo** (Corto Plazo) | Estado actual de la tarea: objetivo, hechos acumulados, hipótesis activas, enfoques fallidos. | `WorkingMemory` |
| **Memoria Episódica** | Historial de búsquedas pasadas: query, query refinado, docs recuperados, score, información faltante, razón de fracaso. | `EpisodicMemory` |
| **Memoria Semántica** | Base de conocimiento del dominio. Simula vector DB; reemplazable por Pinecone/Milvus/FAISS. | `SemanticMemory` |
| **Memoria Procedimental** | Reglas heurísticas sobre cómo buscar. Aprende qué estrategias funcionan. | `ProceduralMemory` |

---

## 3. El Algoritmo MAQRI (Bucle Iterativo)

El motor ejecuta un bucle hasta convergencia o agotar iteraciones:

1. **Verificación de Redundancia:** Compara la query propuesta con consultas recientes en memoria episódica. Si es muy similar, aplica **Estrategia de Divergencia**.
2. **Cross-Retrieval:** Ejecuta la consulta contra memoria episódica, semántica y fuentes externas.
3. **Evaluación y Crítica (The Critic):** Evalúa si los documentos responden a la pregunta. Calcula relevancia, cobertura, novedad e identifica información faltante y razón de fracaso.
4. **Actualización de Memoria:** Guarda el paso en memoria episódica, extrae hechos útiles a memoria de trabajo y registra razones de fracaso.
5. **Condición de Parada:** Si el score de confianza supera el umbral, detiene.
6. **Refinamiento de la Consulta:** Si no converge, usa la crítica para formular una nueva query más precisa.
7. **Síntesis Final:** Una vez terminado, devuelve documentos únicos ordenados con metadata completa.

## 4. Componentes

### 4.1 Memoria Episódica (`episodic_memory.py`)

- `add(episode)`: registra una experiencia.
- `find_similar(query, top_k, threshold)`: encuentra episodios similares.
- `is_redundant(query, window, threshold)`: detecta queries redundantes.
- `get_failed_strategies(n)`: retorna razones de fracaso recientes.
- `get_successful_queries(n)`: retorna queries refinados exitosos.
- `get_lessons_learned(n)`: extrae lecciones aprendidas.

### 4.2 Memoria Semántica (`semantic_memory.py`)

- `add_document(content, source, metadata)`: indexa un documento.
- `add_documents(documents, source)`: indexa múltiples documentos.
- `retrieve(query, top_k, source_filter, min_score)`: recupera por similitud léxica.
- `get_sources()`, `get_stats()`: estadísticas.

### 4.3 Memoria Procedimental (`procedural_memory.py`)

Reglas heurísticas por defecto:

| Regla | Condición | Acción |
|-------|-----------|--------|
| `low_results_expand` | num_results < 3 | EXPAND |
| `low_relevance_diverge` | avg_relevance < 0.3 | DIVERGE |
| `high_redundancy_specialize` | redundancy_ratio > 0.6 | SPECIALIZE |
| `broad_query_focus` | query_too_broad | SPECIALIZE |
| `specific_query_abstract` | query_too_specific | ABSTRACT |
| `add_context` | domain_context_missing | CONTEXTUALIZE |

### 4.4 Divergencia Forzada (`divergence_strategy.py`)

Cuando una query cae en un mínimo local de búsqueda, MAQRI aplica:

- Sinónimos conceptuales (`pricing` → `cost optimization`).
- Cambio de alcance (expandir/especializar).
- Cambio de perspectiva (`how does X work`, `examples of X`).
- Abstracción / generalización.
- Contextualización.

### 4.5 Refinamiento de Queries (`query_refiner_326.py`)

Genera variantes considerando:

- Episodios similares exitosos.
- Reglas procedimentales activas.
- Divergencia forzada si hay redundancia.
- Expansiones estándar.

Refina desde el fracaso combinando objetivo original + información faltante + hechos acumulados.

### 4.6 Módulo Critic (`critic_evaluator.py`)

Evalúa retrieval en tres dimensiones:

- **Relevance:** overlap léxico entre query y documentos.
- **Coverage:** diversidad de contenido entre documentos.
- **Novelty:** información nueva respecto a working memory.

Retorna `missing_info` y `failure_reason` si el retrieval es insuficiente.

### 4.7 Cross-Retriever (`cross_retriever.py`)

Busca simultáneamente en:

- Memoria semántica (base de conocimiento del dominio).
- Memoria episódica (experiencias similares pasadas).
- Fuentes externas inyectables (APIs, otras bases de datos).

Fusiona resultados, normaliza scores por fuente, deduplica por fingerprint y ordena por score.

### 4.8 Motor MAQRI (`maqri_engine.py`)

Orquesta todo el ciclo:

```python
engine = MaqriEngine()
result = engine.search(
    query="How does MAQRI work?",
    context="Building a reasoning layer",
    domain="agi",
    max_iterations=5,
)
```

### 4.9 Capa UC-326 (`UC-326.py`)

Wrapper de alto nivel diseñado para ser inyectado como retriever en UC-325:

```python
from uc326 import UCMaqriLayer

layer = UCMaqriLayer()
result = layer.retrieve_with_context("query", context="...")

# Interfaz simple compatible con UC-325
docs = layer.retrieve("query", top_k=5)
```

## 10. Integración con UC-325

UC-325 puede usar UC-326 como retriever inyectable:

```python
from uc326 import UCMaqriLayer
from uc325 import ReasoningLoopEngine

maqri = UCMaqriLayer()
engine = ReasoningLoopEngine(retriever=maqri)
result = engine.reason("¿Cómo mejorar retrieval con memoria?")
```

`UCMaqriLayer.retrieve()` devuelve documentos en el formato que UC-325 espera:

```python

    {"content": "...", "source": "...", "score": 0.9, "metadata": {}},
    ...
]
```

## 11. Modos de Fallo y Fallback

| Fallo | Comportamiento |
|-------|---------------|
| Sin retriever semántico | Usa memoria episódica y fuentes externas |
| Sin fuentes externas | Funciona con memoria semántica + episódica |
| Query redundante | Aplica divergencia forzada |
| Baja relevancia | Refina query con Critic feedback |
| Sin convergencia | Retorna mejor resultado tras max_iterations |
| Excepción | Capturada, log ERROR, veredicto INSUFFICIENT_DATA |

## UC-324 Safe Shutdown Integration (MAQRI)

UC-326 `MaqriEngine` provides a redacted memory snapshot method for UC-324's `SafeShutdownCoordinator`:

- **`redacted_snapshot(shutdown_id)`**: Returns a hash/manifest + counts (episodic entries, semantic entries, search history), NOT raw memory contents, private memory, or chain-of-thought. The manifest hash is computed over entry counts for integrity verification.

This method is called during the CAPTURING phase of the safe shutdown sequence.
