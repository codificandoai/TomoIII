## Modelo de predicción de declive / sostenimiento

El módulo `forecasting.py` proyecta cada indicador con regresión lineal simple y combina los resultados con el scoring rule-based para estimar:

- `score_riesgo_actual`: score del último corte.
- `score_proyectado_1y`: score esperado en 1 año.
- `probabilidad_declive_pct`: probabilidad de empeoramiento.
- `probabilidad_sostenimiento_pct`: probabilidad de estabilización/mejora.
- `escenario_esperado`: etiqueta interpretativa del escenario.
- `proyecciones_por_indicador`: valor proyectado de cada indicador.

Ejemplo de uso:

```python
import pandas as pd
from forecasting import predecir
from core import analizar_empresa

historial = pd.DataFrame([
    {"empresa": "E", "fecha": "2023-12-31", "indicador": "Ingresos netos por ventas", "valor": -10.0},
    {"empresa": "E", "fecha": "2024-12-31", "indicador": "Ingresos netos por ventas", "valor": -26.71},
])
prediccion = predecir(historial, horizonte_anios=1)
```

## API REST Flask

La API expone los endpoints:

| Método | Endpoint | Descripción |
|---|---|---|
| GET | `/health` | Health check |
| GET | `/api/v1/schema` | Card views de entrada y salida |
| POST | `/api/v1/analyze` | Análisis financiero rule-based |
| POST | `/api/v1/predict` | Análisis + predicción de declive/sostenimiento |
| POST | `/api/v1/batch` | Procesar CSV/Excel multiempresa |
| GET | `/api/v1/metrics` | Métricas Prometheus |
| GET | `/api/v1/dashboards` | Dashboards Grafana generados |

### Card View — Parámetros de Entrada

#### `POST /api/v1/analyze`

| Parámetro | Tipo | Requerido | Ejemplo | Descripción |
|---|---|---|---|---|
| `empresa` | string | Sí | `"Empresa S.A."` | Nombre de la empresa |
| `cortes` | list[object] | Sí | `[{"fecha": "2024-12-31", "indicadores": {...}}]` | Cortes anuales/trimestrales |

#### `POST /api/v1/predict`

| Parámetro | Tipo | Requerido | Ejemplo | Descripción |
|---|---|---|---|---|
| `empresa` | string | Sí | `"Empresa S.A."` | Nombre de la empresa |
| `cortes` | list[object] | Sí | `[{"fecha": "2023-12-31", ...}, {"fecha": "2024-12-31", ...}]` | Mínimo 2 cortes para tendencia |
| `horizonte_anios` | integer | No | `1` | Años de proyección |

### Card View — Parámetros de Salida

#### `POST /api/v1/predict`

| Campo | Tipo | Descripción |
|---|---|---|
| `empresa` | string | Nombre de la empresa |
| `fecha_analisis` | string | Último corte analizado |
| `score_riesgo_actual` | float | Score de riesgo actual (0-100) |
| `score_proyectado_1y` | float | Score proyectado a 1 año |
| `probabilidad_declive_pct` | float | Probabilidad de declive |
| `probabilidad_sostenimiento_pct` | float | Probabilidad de sostenimiento |
| `escenario_esperado` | string | Etiqueta del escenario |
| `nivel_riesgo_proyectado` | string | Nivel de riesgo proyectado |
| `proyecciones_por_indicador` | object | Valor actual y proyectado por indicador |
| `indicadores_en_declive` | list | Indicadores cuyo riesgo empeora |
| `analisis_actual` | object | Resultado completo del análisis rule-based |

## Notas de implementación

- El análisis rule-based conserva los umbrales heurísticos originales.
- La proyección utiliza regresión lineal simple por indicador; es una aproximación adecuada cuando se dispone de pocos cortes históricos.
- El score proyectado y las probabilidades son orientativos y no reemplazan un modelo de insolvencia calibrado ni el juicio de un analista financiero.
